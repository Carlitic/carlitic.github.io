# Portfolio Personal - Carlos Javier Castaños Blanco

Bienvenido a mi portafolio personal. Aquí presento mis habilidades, trayectoria y proyectos en el desarrollo de aplicaciones web.

## 🚀 Sobre el Proyecto

Este sitio web ha sido diseñado para mostrar mi experiencia y conocimientos como estudiante de Desarrollo de Aplicaciones Web (DAW) y mi formación previa en Sistemas Microinformáticos y Redes (SMR).

El diseño se centra en una estética moderna, limpia y profesional ("Premium"), utilizando un esquema de colores oscuros con acentos en violeta.

## 🛠️ Tecnologías

Este portafolio está construido utilizando tecnologías web modernas:

-   **HTML5 & CSS3**: Estructura semántica y estilos avanzados.
-   **CSS Variables**: Para un sistema de diseño consistente y fácil mantenimiento.
-   **Responsive Design**: Adaptable a dispositivos móviles y escritorio.
-   **Glassmorphism**: Efectos visuales modernos de transparencia y desenfoque.

## 📂 Proyectos Destacados

### [Adopta Felicidad](https://carlitic.github.io/adopta-felicidad/)
Una plataforma web moderna diseñada para conectar protectoras de animales con personas que buscan adoptar.
-   Incluye gestión de animales y paneles de administración.
-   Diseño intuitivo y amigable.

### [SMR-Hub](https://carlitic.github.io/SMR-Hub/)
Plataforma educativa interactiva para modernizar la enseñanza del Ciclo Formativo de Sistemas Microinformáticos y Redes.
-   Temario estructurado y tests de autoevaluación.
-   Panel de administración para gestión de contenido.

### [Stack-Tools](https://carlitic.github.io/stack-tools/)
Tu navaja suiza digital para organizar recursos de desarrollo. SPA construida con **Vanilla JS** y **Supabase**.
-   **Gestión de Herramientas**: CRUD completo, búsqueda en tiempo real y categorización personalizada.
-   **Backend Serverless**: Autenticación segura y persistencia de datos con PostgreSQL (RLS).
-   **Diseño Premium**: Interfaz responsive con glassmorphism y exportación a PDF.

### [Eco Vecinos](https://carlitic.github.io/ecovecino/)
Plataforma integral de gestión para comunidades de propietarios.
-   **Gestión 360º**: Incidencias, tablón de anuncios, juntas online y agenda de vecinos.
-   **Tecnología Moderna**: Migrado de Firebase a **Appwrite** para mayor escalabilidad y control.
-   **Mobile First**: Interfaz adaptativa con experiencia nativa en dispositivos móviles.
